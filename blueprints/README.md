# Blueprints

Complete setups built from the examples in this repository, each with the
order to apply its files.

| Folder | Builds |
|---|---|
| [`developer-platform/`](developer-platform/) | A path from `git push` to a running service: kpack builds images from source, Kyverno checks what runs |
| [`ai-inference/`](ai-inference/) | A model API on your domain in your AWS account: GPU nodes on demand, a JWT access policy, replicas that scale with waiting requests, cost and GPU metrics |
